Security brief

Intercept records local Windows activity metadata and offers input-protection controls. This is a preview, and it does not guarantee protection against every input mechanism, an elevated attacker, termination by the same user or gaps after Windows removes a hook.

Local by design

No desktop account, telemetry or automatic update checker is required. The public website and download service are hosted by GitHub. Optional desktop enrichment comes from data files you import yourself.

Input evidence

Native input receipts retain recipient identity, timestamps, event counts and the decision metadata. They do not retain typed key values or pointer coordinates. Knowing the recipient and a coincident agent session does not verify the input sender. Blocking requested does not establish what the recipient ultimately received.

Calibrated routes

A trusted agent needs actual signed-image evidence, a live calibrated computer-use indicator and an eligible approved recipient. Coding lineage, a process name and configuration alone do not establish those facts. Calibration and physical behavior remain unproven where the corresponding checks have not been run.

Locked findings

Protected-app input, sensitive sign-in access, decoy access, reduced oversight and protection tampering are intended to remain visible independently of expected-agent rules. Do not rely on a preview route beyond the documented, verified scope.

Downloads

The current Windows installer is unsigned. Compare the SHA-256 published beside it. A matching checksum verifies the bytes, not the identity of a code-signing publisher or Windows reputation. Read the current release notes.

Report a security issue

Use GitHub private vulnerability reporting for sensitive details. Do not attach tokens, local history, credential files or private QA profiles to a public issue.
