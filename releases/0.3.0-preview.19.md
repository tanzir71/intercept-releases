# Intercept Preview 19

This Windows 11 x64 preview improves navigation between Simple and Advanced modes. Alerts retain their search, category and Advanced filters, with visible labels and a clear action. Home customisation opens Input settings, protection coverage focuses Health & limits, and agent-session navigation keeps the selected session and search. Changing the history source retires the old navigation and selection state.

The package also checks that fresh installations start in Simple mode, existing installations introduce Simple mode while opening Advanced, and saved mode choices survive a cold restart. Mode changes retain the collection settings and their existing action history.

This remains a prerelease. Full interface/design and per-caller acceptance are unfinished. Physical input, real-agent calibration, installed-service switching, sign-in/elevation and broad Windows matrices remain optional and unrun. Native activation gates remain unchanged; this release does not establish new input coverage or sender attribution. The desktop source remains private. See [current availability](../docs.html#preview-status) before relying on a designed feature.
