# Intercept 0.3.0-preview.21

This preview improves saved scan information, current configuration reads and agent configuration monitoring.

- Browser profiles show their saved scan's start/completion time. A missing time stays unavailable instead of interpreting a scan ID as a date.
- Configured-posture panels keep the newest refresh result. Older responses cannot replace newer configuration or revive a failed read after a history/context change.
- During manual Agents collection, configuration watching includes overridden Codex/Claude roots, managed settings/drop-ins and separate Codex profiles. Verified, captured session folders also reach the watcher without changing saved project preferences.
- New session folders establish a discovery baseline. Later MCP/hook/plugin changes use the existing locked change warning, with safe metadata and explicit partial coverage when a bound is reached.
- Native ETW traffic observations can participate in the existing secret-then-new-destination warning while retaining their transport action and byte totals. The warning reports timing correlation, not proof that a secret was transmitted.

Complete saved privacy-review counts, paging, search and Home-to-Identity drill-down remain available from Preview 20.

This is an unsigned Windows 11 x64 prerelease. Full V5 work is still in progress. Configuration does not establish runtime permissions, sender identity or an active input allowance. Physical/real-agent calibration, installed-service/SCM/UAC, sign-in/elevation and broad Windows/regression matrices remain optional and unrun. Native activation gates are unchanged.
