# Intercept 0.3.0-preview.20

This Windows 11 x64 preview improves the interface and saved privacy reviews.

- Home, Alerts and Privacy show complete saved review counts, with bounded pages and search across all current scan results. A review beyond the first 200 opens its exact saved metadata, including extension permissions and installation source.
- Home’s Privacy & sign-ins card opens the complete review list. Alerts retains its page and filters when switching between Simple and Advanced modes.
- Settings cards and buttons keep their intended size. Feature-header decoration is aligned, old privacy results retire when history changes, and a replacement Undo notice gets its full display time even when two histories reuse a ledger number.

All review reads stay local. A changed scan asks for a reload rather than mixing pages. Reading saved results does not start a scan, collection or input protection.

This is a prerelease, and the full V5 handover is still in progress. Physical input/agent calibration, installed-service and elevation checks, and broad Windows matrices remain optional and unrun. Native activation gates are unchanged; recipient-based exceptions are not enabled from metadata checks alone. V5 continues to ship in light mode pending approval of the dark design.

The public repository contains the website and installer releases. Desktop source remains private; binary provenance records the implementation commit and installer checksum.
