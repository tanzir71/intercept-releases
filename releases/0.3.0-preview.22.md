# Intercept 0.3.0-preview.22

This preview corrects collection-source dependencies and makes finding and app-policy acknowledgements match their saved actions.

- During manual collection, selecting Agent configurations alone now also requests the process-lineage administrator helper. Startup & persistence and Network posture select their corresponding registry-writer feeds. Declining permission leaves those feeds unavailable while independent local configuration watching and inventories can continue.
- An Agents-only selection keeps file, DNS, traffic, DPAPI and registry providers unselected. Elevated network owner-module snapshots follow selected network categories. Collection stays manual and Pause keeps its existing drain behavior.
- Single and bulk finding actions check the selected history and exact finding IDs before offering Undo. Both permanent ledger views check the restored selection and original action sequence before reporting completion. Bulk Reopen uses the correct native action.
- App notification and recording actions check the app, history and saved target. Notification Undo restores the original policy; recording exclusion acknowledgements check the reviewed revision and scope. Unconfirmed replies request a fresh read instead of reporting success.
- Safer Resume recording still works when its audit is incomplete. The warning remains visible, and Undo never recreates a recording exclusion. Existing observations and original/compensating ledger entries are retained.

The updated interface and Core are packaged together. Full V5 work remains in progress. This is an unsigned Windows 11 x64 prerelease. Physical input, real-agent calibration, installed-service/SCM/UAC, sign-in/elevation and broad Windows/regression matrices remain optional and unrun. Native activation gates are unchanged.
