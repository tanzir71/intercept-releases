# Intercept 0.3.0-preview.30

Windows 11 x64 prerelease. Start collection when you want to observe activity.

- Advanced input settings bring persistence, scope, automation and health into one policy card, alongside the existing agent controls. The settings navigation and heading use the current design and wrap at narrow widths.
- Automation rules can be turned Off while retaining their definitions and order. Changes remain drafts until review and confirmation. Protection reductions default to a native 15-minute restoration; the existing receipt and Undo restore the saved policy. Locked protected-app and lower-integrity rules remain enabled. Older guards refuse unsupported rule-switch saves before writing.
- The Trusted agents shortcut preserves the same mounted draft when switching back to Input protection. Agent identity, configured coding access, current native evidence and saved requests stay visibly distinct. Changing a full-access guardrail opens the existing policy review.
- The approved-scope caption shows enabled, exact rules for the selected agent. Collection watch folders do not establish approved scope. Adding protected apps preserves existing installed defaults while discovery loads.
- Appearance, density and help remain available through the local-status menu. Its panel keeps the collection control accessible, and Escape restores focus.

All processing stays on the device. The desktop source repository remains private.
The public repository contains the website, installer and release facts.

Complete Handover 5/6 screen/state, caller and data-path acceptance remains open.
Physical input, real-agent calibration, installed-service/elevation and broad
Windows/history matrices remain optional and unrun. Native activation gates and
the light-first release policy are unchanged.

provenance before running it.
