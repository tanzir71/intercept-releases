# Intercept 0.3.0-preview.32

Windows 11 x64 prerelease. The desktop implementation remains private; the public repository contains the website and installer distribution.

- Advanced Overview now brings the heading, activity chart, guard status, attention items and saved feed together in the complete frame. Saved requests, current observations and unavailable evidence remain distinct; filters and detailed controls stay available.
- The Trusted agents tab in Advanced Alerts now uses the shared current native status. Missing evidence is shown as unavailable. Its settings and session links open the existing Advanced destinations.
- Advanced Agents now has one page heading. Live status and collection controls remain accessible together, fit narrower windows and return focus when closed with Escape. Full source paths, saved-read reviews and all native guardrail categories remain available.
- Switch styling is consistent across protection, agent approvals, automation and full-access guardrails. Embedded switch shadows have been removed from the shipped artwork.

Four fresh reports pass 63 essential checks: twelve native/API checks and 51 packaged GUI checks. They cover reviewed settings, Cancel, holds, restoration, Undo, mode restart/upgrade and the changed Advanced screens at three widths. The package remains source-bound and unarmed during these disposable checks. An unavailable computer-use report is not presented as a calibrated session.

The release assets provide the installer checksum and binary provenance. The installer is unsigned. Full V5 state/caller and remaining producer/Store/rules/export acceptance remains in progress.

Native validation gates remain enforced. A saved On request does not prove active input hooks or continuous protection. Windows-flagged keyboard/mouse input is the controllable route; other routes are not represented as paused. Recipient/time-window allowances do not identify the sender.

Physical input and real-agent calibration, installed-service/SCM/UAC, sign-in/elevation and broad Windows/history matrices remain optional and unrun. The dark-theme proposal remains unapproved under D34; shipping stays light first. No owner settings, credentials, agent configuration, installed service or real-input experiment is part of these disposable checks.
