# Intercept Preview 33

Preview 33 improves input-control recovery and saved coding-session presentation on Windows 11 x64.

- Emergency input release now defaults to restoration after fifteen minutes. Choose one hour, app restart where supported, or Never; the result confirms whether restoration and action recording were saved.
- Tray release opens the held control, including while a Pause request is pending. Normal and recovery controls validate the native reply and preserve the current history and guard identity.
- Late process-lineage records can recover through bounded retries instead of staying unavailable for the entire collection run.
- Process and destination panels retain distinct identities when a saved coding session is reopened.

The desktop source repository is private. This public repository contains the landing page, documentation, release metadata and installer assets.

Essential release checks use disposable histories and an unarmed guard. Broad Windows, installed-service, physical-input and actual-agent calibration remain optional and unrun. Native activation gates and dark-theme approval remain unchanged; configured agent posture does not establish runtime permissions.
