# Intercept 0.3.0-preview.15

- Keeps personal guard approvals, settings, trusted-agent policy, Ledger reads and guard Undo available while connected to the Windows service. The collection service retains its separate history.
- Preserves those personal controls after a collection connection fails. Recovery shows the guard and available approvals; collection status stays explicitly unavailable until a fresh connection succeeds. If personal history cannot open, held emergency release remains available.
- Adds reviewed service installation/start and held stop/startup reductions, with saved receipts and restoration choices. Service removal requires a typed confirmation and keeps its history. Administrative operations still require the appropriate Windows permissions.
- Reviews ordinary collection settings before applying them, records their outcomes and supports scoped Undo. Windows login startup reports its actual registration outcome.
- Reviews adding a fixed sample observation and importing a selected SRUM copy, retaining an approval and outcome in the actions Ledger. Raw legacy mutation routes are refused.
- Retains the previous app-restart restoration, Off-only legacy guard upgrade and responsive landing/documentation fixes.

Full V5 remains unfinished. Reviewed backend switching, quit/lifecycle handling and reverse guard-host selection are still in development. Collection recovery does not confirm that a Windows service is running or collecting. The independent guard can retain its saved request after a Core interruption; requested protection and actual hook availability remain distinct.

This is an unsigned Windows 11 x64 prerelease. Native activation gates remain unchanged. Physical input/timing, actual sign-in/elevation and SCM/UAC changes, real-agent AG-1 and the broad Windows build matrix were not exercised for this release. Fresh disposable checks explicitly disable input hooks. Compare the published installer checksum before use.

App-restart restoration uses profile storage v6. Downgrading a used v6 profile is unsupported. Existing profiles that do not use that choice retain their earlier storage requirements.
