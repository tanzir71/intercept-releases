# Intercept 0.3.0-preview.23

This preview connects the Advanced input sidebar to current native status and adds saved context and activity summaries to agent-session details.

- Advanced Input settings shows the shared current agent status and the existing reviewed agent-policy and guardrail controls. Unavailable or disconnected evidence stays explicit.
- The configured-posture reader is available in Advanced Input settings. It reads the selected configuration context without changing agent settings. Configured values do not establish current runtime permissions or computer-use trust.
- Agent-session details show the saved launch folder and configured posture when they are bound to the recorded process instance. Older records without those fields remain unavailable.
- Activity summaries count all saved write observations before the displayed row limit, distinguish recorded approved scope from outside or unverified scope, and retain locked and additional guardrail totals.
- Destination rows include the recorded process, scope and native-accounted bytes when available. A measured zero remains zero; missing accounting stays unavailable. Local session exports retain the same saved context and summaries.
- The Advanced sidebar now wraps long status labels within its cards.

The interface and Core are packaged together. Full V5 work remains in progress. This is an unsigned Windows 11 x64 prerelease. Physical input, real-agent calibration, installed-service/SCM/UAC, sign-in/elevation and broad Windows/regression matrices remain optional and unrun. Native activation gates are unchanged.
