# Intercept 0.3.0-preview.28

Windows 11 x64 prerelease. Start collection when you want to observe activity.

- Simple AI agents uses the original local artwork and responsive session, scope and guardrail cards. Live-root checks, recorded configuration and unavailable evidence remain distinct.
- Advanced Alerts retires replaced recipient reviews and selections, preserves the owner of an in-flight save, and counts distinct saved evidence references. A recipient rule does not identify an input sender.
- Advanced session detail now follows the three-column A4 layout, with compact lineage, aligned activity metrics, destinations, flagged events and local export controls.
- Process finding badges use exact saved process-instance evidence. Reused names and PIDs cannot transfer a badge to another process. Report finding references stay within the selected session; original history and findings remain intact.
- An individual credential or decoy read can be recorded as expected for that saved event, path and verified agent. This records a scoped review; it does not disable the guardrail or suppress new reads. Both ledgers preserve its receipt and exact Undo target across restart.

All processing stays on the device. The desktop source repository remains private.
The public repository contains the website, installer and release facts.

This preview does not certify complete Handover 5/6 acceptance or full A4 pixel
parity. Runtime permission and collection gaps remain explicit. Broad physical
input, real-agent calibration, installed-service/elevation and Windows/history
matrices remain optional and unrun. Native activation gates and the light-first
release policy are unchanged.

The installer is unsigned. Compare its SHA-256 with the release checksum and
provenance before running it.
