# Intercept 0.3.0-preview.24

This preview improves rule-change receipts and Undo, the Advanced Overview, and the process identity used for DNS destination inference.

- Rule changes acknowledge the complete reviewed policy. Undo checks the original action and its exact inverse; the shared Undo notice opens a review before saving the restoration.
- The Overview Live feed shows seven event fields, keeps active filters visible and uses compact rows when its panel is narrow. Confidence and process attribution have separate labels.
- Overview metric captions explain the current saved evidence. The activity chart fills its panel and retains up to 80 time buckets.
- Needs attention rows show severity, finding, subject, source and attribution, last seen and available actions. Narrow panels use stacked rows; additional actions stay in a menu. Missing evidence remains explicit.
- DNS destination inference now requires the same process creation identity. A new process reusing the same PID and image cannot inherit the earlier process's answer. Exactly 60 seconds remains eligible; an answer older than that expires without rounding to whole seconds.

The interface and native Core are packaged together. DNS is still an inference, not proof of a requested hostname or transmitted content. Ambiguous names retain ordinary alert behavior, and locked findings retain their existing treatment. Existing saved events and exports are preserved.

This is an unsigned Windows 11 x64 preview. Verify the published checksum before installation. Native calibration and activation gates are unchanged. Physical input, real-agent calibration, installed-service switching and broad Windows regression matrices remain optional and unrun. Full V5 screen/state, caller and data-path reconciliation remains in progress; this preview does not claim full completion.
