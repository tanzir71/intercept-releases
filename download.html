Install

Install in four steps.

Preview builds are unsigned, so the first run takes one extra click. Nothing is recorded until you start monitoring, and nothing leaves your PC.

PS> Get-FileHash .setup.exe
​

01

Check the file

Run Get-FileHash in PowerShell and compare the result with the SHA-256 above. A match proves the bytes, not who built them.
