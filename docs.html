What this installer includes

Reviewed input-guard settings, protected-app editing, ordered automation rules, trusted-agent policy, local evidence and history controls. Native session observations require calibration tied to the exact executable and Windows build.

What is still in development

The website follows the approved V5 design and its product screens contain sample data. Full V5 is unfinished. Native callback agent allowances, durable decision recovery, configured Codex recipient resolution, additional lifecycle and recovery behavior, shared summaries, complete action parity and other V5 details are being completed in subsequent source updates. Features developed after Preview 10 are not part of its installer.

Physical input trials, real-agent AG-1 calibration, S29–S36 matrices, elevation trials and large-history acceptance checks have not established support for the unproven routes. Extensive testing is optional under the owner's delivery instruction; missing implementation and missing native calibration remain explicit.

Protection boundaries

Windows-flagged injected keyboard and pointer input is different from virtual HID, UI Automation, browser DevTools input, physical input or events on another desktop. Recipient/time evidence does not identify an input sender. A request to block is not a measurement of delivery at the recipient.

Trusting an agent, using its coding tools or adding an app ID does not establish an active computer-use session. Unsupported or stale native evidence must not activate an exception.

Source availability

This public repository contains the website and binary distribution records. The desktop implementation repository is currently private. The installer is MIT-licensed, but this distribution repository does not contain the full desktop source or its private history. The website's source and assets can be rebuilt with Node 24 and npm.

Updates

The desktop app has no automatic update checker. New previews and checksums are published on the public Releases page. Install a newer version deliberately after reviewing its notes.

Privacy

The application keeps recorded activity on the device. There is no account or telemetry. Optional enrichment uses locally imported data. Visiting this public website or downloading an installer contacts GitHub's hosting infrastructure; this is separate from the desktop app's local operation.
