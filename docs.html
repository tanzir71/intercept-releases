Good to know

Source availability

The website and release records are public. The desktop source repository is currently private; each installer’s binary-provenance.json names the exact source commit it was built from.

Updates

The desktop app has no update checker. New previews are published on GitHub Releases with their checksums. Install a newer version deliberately, after reading its notes.

Privacy

Recorded activity stays on your PC, with no account or telemetry. Visiting this website or downloading an installer contacts GitHub’s hosting, which is separate from the app.
