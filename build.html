Build from source

Build the Intercept desktop app and this website yourself, and check a published installer against the source it came from.

Updated 19 Nov 2026

·

Node 22.12+ · Rust stable

·

10 min read

Before you start

The desktop source repository is currently private.

These steps apply once it is published. Until then you can build this website from its public repository, and check each installer against its SHA-256 and binary-provenance.json, which names the source commit.

Cloning the repository

Build the desktop app

PowerShell
# From the repository root
# Install exact dependency versions
npm ci
​
# Run the app from source, with a debug native build
npm run desktop
​
# Build the Windows installer (NSIS, x64)
npm run desktop:build

The installer is written to release/phase2/. Builds you make are unsigned unless you sign them yourself. Electron is bundled, so the installed app needs neither Node nor WebView2.

Script

What it does

npm run dev

A browser design preview with clearly labelled sample data

npm run storybook

Component review at localhost:6006

npm run desktop:pack

An unpacked release app for local checks

Run the checks

PowerShell
cargo fmt --all -- --check
cargo test --workspace
npm run build
npm test
npm run test:desktop
npm run storybook:build

npm run check runs the full set in one go. Physical input trials and agent calibration need a disposable Windows account or VM; see the coverage notes before running them.

Build this website

The website, release notes and checksums live in the public intercept-releases repository.

Node 24
git clone https://github.com/tanzir71/intercept-releases.git
cd intercept-releases
npm install
npm run build

The build renders static HTML and CSS with self-hosted fonts and icons. Nothing in the delivered page calls an external service.

Check a published installer

Compare a published installer’s SHA-256 with its release, then read binary-provenance.json to find the source commit it was built from.

PowerShell
Get-FileHash .\Intercept-0.3.0-preview.14-x64-setup.exe -Algorithm SHA256
