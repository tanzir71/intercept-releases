0.3.0-preview.13

LatestPrerelease

19 Nov 2026 · Windows 11 x64

  • Improves recipient identification for child windows, owned popups and packaged Windows apps, with window-event cache updates and process-creation checks.
  • Saves observed daily renewal and bypass totals across guard restarts. The health panel shows when recording began and reports unavailable totals when saving fails.
  • Adds a configurable physical-inactivity threshold, defaulting to five minutes. Longer delays require reviewed approval and a restoration choice; saved receipts, restart recovery and Undo retain the setting.
  • Adds durable away-return summaries with app recipients and unresolved counts. Return notifications respect your notification preference and wait for it during startup. No input values, window titles or sender attribution are recorded.
  • Restores the base policy on return and corrects session-state initialization and fallback restoration.

This is an unsigned Windows 11 x64 prerelease. Native protection, recipient and away routes still require their existing physical and build-bound calibration. This release does not establish that calibration. Physical input/timing, actual Windows notification delivery, real-agent AG-1, elevation/sign-in and Windows build matrices remain optional and unrun. Compare the installer checksum before use.

Custom away thresholds and their retained restoration records use profile storage v5. Downgrading a used v5 profile is unsupported. Default settings retain their earlier serialization.

Full V5 remains in progress: service/legacy-host integration, remaining lifecycle/recovery work, elevation scope and remaining action/design/startup parity are still open. The original completion deadline is unchanged.

0.3.0-preview.12

Prerelease

18 Nov 2026 · Windows 11 x64

  • Agent-policy Undo stays available when you change tabs, with reviewed Undo on permanent action rows.
  • Refreshing agent allowances requests fresh verification from the guard's saved policy and invalidates the previous generation. A refresh acknowledgement does not mean an allowance is active.
  • Closing Intercept and switching collectors have bounded waits. An unconfirmed save is retained for retry, and a healthy Core that is still draining is preserved.
  • This session protection follows the app process. Replacing Core, restarting the guard or opening history-free recovery preserves the request; exiting the app ends it. Direct command-line clients retain their own process lifetime.

This is an unsigned Windows 11 x64 prerelease. Native input routes and agent allowances still require their existing physical and build-bound calibration. This release does not establish that calibration. Compare the published installer checksum before use. Downgrading a used storage-v4 profile is unsupported.

Full V5 remains in progress, including service and legacy-host integration, elevation plumbing, recipient prewarming/UWP handling, away-return UX, durable daily totals and remaining action/design parity. Extensive regression, real-agent AG-1, physical input, elevation/sign-in and Windows build matrices remain optional and unrun. The original completion target is unchanged.

0.3.0-preview.11

Prerelease

18 Nov 2026 · Windows 11 x64

Windows 11 x64 prerelease. The desktop source repository remains private; binary-provenance.json identifies the exact source commit and installer bytes. The public tag identifies this distribution repository's commit.

  • Current native computer-use status is shared across protection, simple/advanced agents, Home and the advanced overview. Saved coding sessions remain separate. Recipient permissions expire independently from session indicators; stale or disconnected evidence is unavailable.
  • Native callback decisions connect calibrated current sessions, eligible recipients, bounded recording and authenticated durable metadata receipts. Protected-recipient input has a separate receipt path, and locked alerts can import while ordinary collection is paused.
  • Codex configuration-derived recipients require exact installed identity and a calibrated app-ID/image mapping. Configuration changes revoke the previous generation. Policy review, checked panel Undo and preservation of dirty drafts remain available.

Actual signed-image evidence and a guard/build-bound AG-1 calibration record are required before native agent allowances can activate. No passing real-agent calibration was created for this release. Recipient/time evidence retains an unknown sender and does not prove input delivery. The installer is unsigned; compare the published SHA-256 before use. Both matching Core and guard are included; downgrading a used storage-v4 profile is unsupported.

Production native/UI builds and exact package binding passed. Thirteen isolated policy API checks and eleven packaged GUI checks passed with collection paused and hooks unarmed. Fifteen focused UI cases and the indexed-lookup check passed. The public page passed desktop/mobile checks with 485 loaded images, 41 links, seven FAQs and no external renderer requests. These are focused checks; they do not establish physical input behavior.

Broad regression, physical input/timing, real-agent AG-1, Windows/elevation/sign-out matrices, S29–S36 and large-history acceptance remain optional and not run. UI metadata fixtures do not count as calibration.

Full V5 is unfinished. Remaining work includes the legacy allowance command's verified flow, global/permanent agent-policy Undo, lifecycle/service/quit recovery, elevation plumbing, recipient prewarming/UWP handling, away-return UX, durable daily health totals and remaining action/design parity. The original 24-hour target elapsed; usable previews and repository updates continue.

0.3.0-preview.10

Prerelease

18 Nov 2026 · Windows 11 x64

Windows 11 x64 prerelease, built November 18, 2026. This is the same installer originally produced for Preview 10, now distributed publicly. It does not include source changes made after desktop commit 7bd27f6895c150684384e8430efe00566b705a70.

Includes reviewed trusted-agent policy settings, protected-app editing, ordered guard automation, local history controls and native computer-use session observations gated by exact executable/Windows calibration.

Full V5 is unfinished. Callback agent allowances and durable decision recovery, configured Codex recipient resolution, additional lifecycle/health/return behavior and complete action parity remain subsequent work. The public website follows the approved design; its product screens show sample data. Check the current availability and security brief.

Essential source, artifact, policy API and packaged GUI checks were performed for the original Preview 10 build. Physical input, real-agent AG-1 calibration, elevation and broad Windows/S29–S36 matrices remain optional and not run. This release does not establish passing calibration, continuous input coverage or recipient delivery. No keys, pointer coordinates or verified input-sender claims are added by publishing it here.

binary-provenance.json records the desktop source commit separately from the public distribution tag. The desktop implementation repository remains private; this public repository contains the landing page and release records. Internal QA profiles and private audit artifacts are not public release assets.
