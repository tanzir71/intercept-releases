0.3.0-preview.29

LatestPrerelease

21 Nov 2026 · Windows 11 x64

Windows 11 x64 prerelease. Start collection when you want to observe activity.

  • Interface mode, density, theme preference and the one-time Simple introduction now live in per-user app configuration outside event history. Changing the selected history or switching between desktop and service connections keeps the app's appearance choice.
  • Existing appearance preferences migrate once. Fresh installations open Simple; existing installations without a mode choice open Advanced with the Simple introduction. Saved history and earlier action receipts remain intact.
  • Appearance changes keep their receipts in the initiating history's existing encrypted ledger. Undo checks the shared app revision and mutation reference, so an older history cannot overwrite a newer choice merely because the values match. Service-mode toast and Ledger Undo use the personal action history.
  • Saved-session Timeline links, session tabs and the all-agent Timeline link retire with their source. Callbacks retained from an old history or backend cannot change the current view or filter.

All processing stays on the device. The desktop source repository remains private. The public repository contains the website, installer and release facts.

This preview does not certify complete Handover 5/6 acceptance or full screen parity. Broad physical input, real-agent calibration, installed-service/elevation and Windows/history matrices remain optional and unrun. Native activation gates and the light-first release policy are unchanged.

The installer is unsigned. Compare its SHA-256 with the release checksum and provenance before running it.
