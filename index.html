OVERVIEW

Visibility first. Control where it counts. Evidence for every claim.

Windows tells you an app used the microphone. It rarely tells you which process, on whose behalf, or what else it touched. Intercept joins those signals into one local record, says how each field was obtained, and marks unknowns as unknown instead of guessing.

How attribution works

Attribution, not guesswork

Every event names the app, its publisher signature, the process that launched it and the source of each field. Services hosted in svchost are named. Missing values say why they are missing.

Input protection with no time limit

Blocks software-generated typing and clicks in password managers, terminals and Windows Security. Armed at sign-in, checked for gaps, and honest about the routes it cannot reach.

Built for AI agents

Claude and Codex are verified by signature and recorded without false alarms, including coding sessions with full access. Credential access and config changes always alert.

CAPABILITIES

One workspace for every signal on the device.

Sensors, network, sign-ins and synthetic input share one timeline, one set of findings and one actions ledger. Simple mode shows what needs you. Advanced mode keeps every row.

SECURITY AND PRIVACY

Designed to pass a security review.

A privacy tool should be held to a stricter standard than the apps it watches. These are design commitments, and the code is open so each one can be checked.

NO TELEMETRY

Intercept sends nothing about you or your PC to anyone. There is no account and no update checker.

ZERO EGRESS

Fonts are bundled, signature checks run offline, and GeoIP or tracker data come only from files you import.

NEVER READS SECRETS

Browser and Credential Manager reviews read metadata: names, ages and permissions. Never passwords or cookie values.

HISTORY IS NEVER TRIMMED

Migrations only add. Deleting anything you own takes a typed confirmation and a single-use plan.

ONE ACTIONS LEDGER

Every decision, from “mark expected” to a deletion, is recorded locally and can be reviewed or undone.

LEAST PRIVILEGE

The app runs as a standard user. Admin rights are requested only for optional features, one at a time.

VERIFIED BY SIGNATURE

Agents and protected apps are matched by publisher signature, so a renamed copy is never trusted.

MIT-LICENSED

Read the code, build it yourself and verify every claim on this page. Beta builds are not yet code-signed.

Does Intercept send any data off my PC?

No. There is no telemetry, no account and no update checker. Optional enrichment such as GeoIP or tracker lists uses files you import yourself.

Will it block Claude or Codex?

Trusting an agent alone does not enable input exceptions. A current native calibration, a live computer-use session and an approved recipient are required. Protected apps remain excluded. See the current preview limitations before relying on this route.

Can it stop every kind of synthetic input?

No. The native guard covers Windows-flagged keyboard and pointer input on the supported interactive desktop. It cannot promise coverage of virtual HID devices, browser DevTools input, UI Automation actions, other desktops or gaps after hook removal. Physical and real-agent calibration remain unproven in this preview.

Does Intercept read my passwords or browsing history?

Intercept records metadata and does not retain key values or pointer coordinates. Its credential-path guardrails are intended to report access to sensitive locations without storing password or token contents. Preview behavior and optional enrichment are described in the security brief.

Does it need administrator rights?

The desktop app can run as a standard user. Some collection or elevated protection routes require separate permissions. This preview does not claim protection from an elevated attacker or from termination by the same user.

Why does Windows show a SmartScreen warning?

This preview installer is unsigned and may be unfamiliar to Windows SmartScreen. Check the published SHA-256 before installation. A checksum verifies the downloaded bytes; it does not establish publisher signing or Windows reputation.
